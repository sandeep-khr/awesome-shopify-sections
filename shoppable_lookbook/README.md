# Shoppable Lookbook Section

A high-end, interactive "Lookbook" section that allows merchants to tag products within a lifestyle image. This functionality is often found on luxury fashion and home decor sites.

## Features

-   **Interactive Hotspots**: Pulse animation to guide user attention.
-   **Product Cards**: Glassmorphism-styled cards that appear on click/hover.
-   **AJAX Add-to-Cart**: Add products directly from the lookbook without leaving the page.
-   **Mobile Reponsive**: Cards gracefully handle edge detection to stay on screen.

## Installation

1.  Copy the content of `section-shoppable-lookbook.liquid` into your theme's `sections/` folder (or create a new section file).
2.  Add the section to your theme via the Customizer.
3.  Upload a main image.
4.  Add "Product Hotspot" blocks.
5.  Select a product for each block and adjust the `Horizontal Position` and `Vertical Position` sliders to place the dot over the item in the image.
